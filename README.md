# Sec-Vibe
Cybersecurity learning hub featuring security tools, OSINT, web and cloud security, digital forensics, CTF labs, bug bounty resources, commands, certifications, and career guides. Built with vanilla HTML, CSS, and JavaScript for responsible security learning.

Sec-Vibe — Security Learning Hub
A single-file, browser-based cybersecurity learning hub for exploring security tools, operating systems, web and cloud security, OSINT, digital forensics, CTF practice, certifications, scholarships, bug bounty programs, commands, and career resources.

Built with: HTML, CSS, and vanilla JavaScript. No framework, package installation, build step, external font, or runtime API key is required.

Ethics & authorization: For education and authorised testing only. Never target systems you do not own or have written permission to test. Always check the scope and rules of each lab or vulnerability disclosure programme.

Features
31 navigation tabs, including Home, Dashboard, and 29 topic sections
Search across sections and filter resources by tags, favourites, and learning progress
Save favourites and mark resources as learned
Dashboard with progress summary and JSON progress export/import
Four colour themes
Keyboard-accessible command palette and navigation
Copy buttons for command examples
Responsive dark interface
Hash-based navigation for linking to sections
Local browser state; the app does not send your favourites or progress to a server
No third-party runtime dependencies or analytics
Run locally
Download index.html from this repository.
Open index.html in a modern browser.
Browse the catalog, search, save favourites, and track what you have learned.
The page is designed to work as a local HTML file. Some browser features, especially service-worker-based offline caching and PWA installation, require a separately configured secure web origin and are not provided by this single-file build.

Publish with GitHub Pages
Create a GitHub repository named sec-vibe (or another name you prefer).
Upload index.html to the root of the repository. Keep the filename exactly index.html.
In the repository, open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Choose branch main and folder /(root), then save.
After GitHub Pages finishes deploying, open the URL shown on the Pages settings screen. For a repository named sec-vibe, it typically follows https://darkbro-ops.github.io/sec-vibe/.
Responsible-use guidance
Sec-Vibe is a learning index and reference hub, not permission to test a target. Only practise in your own lab, intentionally vulnerable training environments, or systems for which you have explicit written authorization. Follow program scope, rate limits, disclosure rules, and applicable law. This project is not legal advice.

Data quality
Resources are linked to their respective project or documentation sites where available. Websites can change, move, require accounts, or discontinue programmes. Verify a resource and its current rules before relying on it. Related resources may be cross-listed in more than one section; section entry counts therefore do not represent globally unique tools.

Contributing
Suggestions for useful resources, corrected links, accessibility improvements, and bug reports are welcome. Please include the affected section, the official resource URL, and a brief explanation. Do not submit secrets, private target data, or information obtained without authorization.
